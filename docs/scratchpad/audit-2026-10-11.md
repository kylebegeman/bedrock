## Key repairs

### Approved source and revision identity

Interactive confirmation now applies the displayed digest. Local deploy plans
bind source bytes, modes, directories and safe relative links. Execution copies
and verifies a private source tree before database initialization, static
packaging or image builds. Recovery can use that capture after the original
checkout disappears.

Component-wise link resolution rejects composed symlink escapes. Root-bound,
no-follow, nonblocking file opens reject swapped links and special files before
reading. Copy and hash lengths are bounded by inspected file sizes. Dockerfile
validation and the builder both refuse escape from the build context. Capture
preflight accounts for sparse logical bytes and preserves 5 GiB of free space.

Revision creation uses an atomic insert rather than an upsert. Reusing an
existing revision cannot overwrite live status, image references or pinned
secrets. Replays preserve already recorded progress. Successful source copies
are removed; garbage collection removes terminal captures while retaining trees
with unfinished, missing or mismatched ownership.

### Runtime, images and removal

Docker adoption checks owner, app, workload, revision and requested identity.
Foreign resources are refused, transient inspection errors remain errors, and
create conflicts are reinspected. Interrupted network attachments are completed;
stdin attaches before an adopted stopped container starts. Pull errors embedded
in progress streams are reported.

Images retain immutable digest or imported image-ID references. Garbage
collection recognizes digest references and retains revisions and images needed
by open jobs. `remove --data` gathers exact volumes from every recorded revision,
shows them in the plan and refuses malformed or mismatched history.

### Jobs and recovery authority

Queued cron and operator jobs revalidate the active revision after acquiring the
data lock. Random job names replace millisecond names. Execution and cleanup
use validated immutable container IDs, including after failed starts. Transient
ownership uncertainty leaves the durable run open rather than permitting cron
overlap. Missing containers and Docker outages are distinguished.

Startup reconciliation retries unresolved jobs, avoids duplicate trackers,
adopts surviving writers and preserves their original execution deadlines.
Timeouts stop the exact writer before closing the run. Daemon cancellation
leaves surviving cron jobs adoptable. Interrupted arbitrary operator commands
are not automatically replayed.

Completed machine cutover replay cannot replace a newer deployment. Move staging
cannot regress cutover state. Recovery preflight validates every runtime identity
before mutation. Rehearsal cleanup records its start durably, stops all writers
before deleting restored data and retains that data if stopping fails. Sealed
identity and history writes are atomic and synced. Handoffs accept one complete
JSON document with a valid app name.

### Backup and state durability

Backup receipts bind the exact operation, durable run, full snapshot ID and
summary. Recovery and retention never substitute the repository's latest backup.
Missing preparation receipts fail before touching staging belonging to another
backup. Helper names are unique; cleanup uses owned container IDs, separate
logging and removal budgets, and explicit cleanup errors.

State databases and existing WAL, SHM and journal sidecars are private. State
backup replacement preserves the old destination until success and syncs the
copy and directory before returning. Activation refuses nonexistent revisions.
Verified release downloads atomically replace assets while preserving existing
assets on failure.

### Daemon, API and diagnostics

A lifetime daemon lock precedes startup mutations. Lease renewal covers recovered
planning, execution and compensation, and renewal goroutines drain. Accepted API
work follows daemon lifetime while surviving client disconnects. Requests accept
one bounded JSON document; queue waits honor cancellation.

Background loops, jobs, webhooks and API operations drain before state closes.
Timed-out HTTP shutdown closes stalled connections. Event writes have a bounded
write deadline and stop streaming after failure while the operation continues.
Request reads and idle connections are bounded too.

Diagnostic lines have bounded storage and serialized writes. Human output
escapes untrusted terminal controls; JSON preserves original values. Terminal
detection uses the actual terminal API. `doctor --json` keeps a failing exit code.

### Transport, secrets and integrations

Remote target, profile and structured response reads are strict and bounded.
Legacy remote deploy shares the strict transport and environment-file exclusions.
Exec and run reject surplus workload arguments. Git archives close rejected
producer pipes and drain successful padding; source directories are unique.
Webhook queues follow daemon lifetime and clean up consistently. Git key changes
are locked, and key paths are quoted.

Present empty secrets survive transfers, copies and bundles. Entire bundles
validate before a single atomic update. Secret paths, versions and sealed
identities validate at their boundary, and secret name listings follow the
committed current pointer. Integration endpoints validate hosts and ports,
refuse embedded credentials and fragments, and do not echo submitted URLs.
Change timestamps compare committed values.

### Host setup, observations and developer workflows

Cloudflare guards replace chains and every existing matching hook in one
netfilter transaction. Inspection checks both available address families and
requires the exact source rules followed by one final DROP. Unexpected rules,
misordered rules and duplicate hooks trigger repair. A Docker unit dependency
prevents startup when an installed guard fails; removing the guard removes that
dependency too. Existing managed swap is persisted without reformatting, and
comment-only SSH key input is refused.

DNS selects the longest matching visible zone and inspects every A destination;
explicit takeover consolidates extras. Certificate probing verifies the real
trust chain and validity. Readiness supports IPv6 and cancellation. SMTP closes
an active conversation on cancellation and keeps a bounded timeout.

Infrastructure outages preserve unobserved incidents; failed recovery notices
retry. Metrics reject nonfinite values, parse escaped labels and avoid key
collisions. Data-only apps receive volume sampling, incomplete disk totals are
omitted, and traffic from shared hostnames is excluded from app attribution.

The lane records provider ownership before fallible metadata probes. Reusing a
stopped owned VM now starts it after identity validation. Product documentation
explains source captures, uncertain job behavior, retention and metric limits.

## Material limits and one unresolved dependency decision

transfer or recovery proof. Earlier live proofs remain historical evidence.

fixtures were not exercised in this pass. No historical production target was
contacted.

safely and require a fresh reviewed backup. Arbitrary interrupted operator
commands likewise require inspection before deliberate re-execution. These are
implemented recovery boundaries, not omitted cleanup work.
